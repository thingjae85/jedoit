# 저두잇

작은 개인 미션을 지인 챌린지로 연결하고, 참여에 따라 공동 책상이 정돈되는 Flutter Web 앱입니다.
현재 구현된 것:
- 개인 미션 4개 체험, 완료 체크·메모를 기기에 기록 (1주차)
- Google 로그인, 로그인 전 체험 기록을 30분 보관했다가 계정에 저장
- 방 만들기·초대 QR/링크(`?invite=`)·참가, 방 전용 닉네임, 시작 확정
- 3일 사진 인증(1280px JPEG 재인코딩, 위치정보 제거), 진행도 H/T와 공동 목표 G
- 공동 책상 그림 (정리된 요소 H개는 가지런히, 나머지는 흐트러짐)
- 내 인증의 사진 삭제·인증 취소 (획득 보상 유지), 계정 삭제 요청 (7일 이내 처리)
- 투두메이트 느낌 화면: 하단 탭(홈·챌린지·기록·마이), 이번 주 날짜 줄과 미션 체크 목록, 월 달력 기록, 방 화면 칸 진행도

- 시작 확정 때 방장이 "오늘부터"(오늘이 1일차) 또는 "내일부터"(내일 0시 시작)를 고른다. 저녁 6시 이후엔 내일부터를 추천
- 진행도는 공동 목표 기준 (목표를 채우면 100%)
- 챌린지 커스텀: 방을 만들 때 종류(정리·책 읽기·공부·운동·직접 만들기)와 이름, 기간(3~60일, +3일·+5일·+7일·+한 달 버튼)을 정한다. 목표는 1인당 기간의 2/3
- 방 인증 방식 선택: 결과(사진·5초 미만 동영상 + 한 줄), 전후(전·후 사진 + 한 줄씩), 가벼운("했어요" + 한 줄)
- 방 피드: 참가자들의 인증이 카드로 쌓이고, 전후 인증은 옆으로 넘겨 보기, 동영상은 눌러서 재생
- 방 피드 자동 새로고침(8초): 친구가 인증하면 바로 나타나고 "방금 인증했어요" 알림
- 응원 리액션 👏🔥: 친구 인증 카드에 종류별로 한 번씩, 다시 누르면 취소
- 오늘의 콜라주: 오늘 인증한 사람들의 사진·한 줄을 한 장으로 모아 보기, 모두 하면 "오늘 모두 정리 완료!"
- 로그인 없이 참여(테스트): QR을 찍으면 바로 참여 방법을 묻고, 게스트로 닉네임만 넣고 참가

- 혼자 쓰는 홈: 홈에는 내 공간과 오늘의 미션만, 친구 줄·초대·방 카드는 챌린지 탭으로 옮김. 챌린지 탭은 누르면 바로 방이 열리지 않고 탭 화면으로 보임
- 내 공간: 도트 쿼터뷰 육각형 방. 처음엔 어둡고 상자가 쌓인 침실이 미션마다 회복되고 가구가 생긴다. 몇 번 남았는지는 보여 주지 않고, 다섯 번째 미션에 새 방(책 읽는 방) 문이 깜짝 열림. 그다음부터는 두 번에 한 번씩 두 방이 번갈아 자람
- 방 카드 오른쪽 위 아이콘으로 하나만 보기 / 벌집 보기. 하나만 보기는 눌러 둔(고정한) 방, 없으면 가장 최근에 바뀐 방. 안 열린 칸은 "문 너머에 뭔가 있어요"
- 캐릭터: 곰인형(비글 색) 또는 햄스터인형(회색). 말풍선을 누르면 바꿀 수 있음. 돌봐 달라고 하지 않고, 해낸 미션에 혼잣말로 반응만 함
- 오늘의 미션: 날마다 몸·마음 하나, 공간 하나, 오늘의 발견 하나. "하나만 해도 충분해요". 내 미션은 2개까지 직접 추가
- 오늘의 발견: 색·모양·물건·실내 풍경·기분 같은 주제가 날마다 바뀌고, '다른 걸로'는 하루 한 번. 사진을 검사하지 않음
- 기록 방식: 모든 미션은 "했어요" 버튼으로 끝남. 타이머·사진·메모는 남기고 싶을 때만. 사진은 이 기기에만 저장(긴 변 360px), 서버에 올리지 않음
- 보상: 미션 보상은 코인(미션마다 10). 추억 보상은 사진을 남기면 방 벽 액자에 도트로 걸리고, 미래의 나에게 쓴 편지는 일주일 뒤 방 카드 우편함에 도착
- 꾸미기(자유 배치): 방 카드의 '꾸미기'에서 가구와 소품을 눌러 고르고 끌어서 아무 칸에나 옮긴다. 한 칸씩 옮기는 버튼도 있음. 다른 가구와 겹치면 원래 자리로 돌아가고, 러그·매트 위에는 올릴 수 있음. 미션으로 생긴 가구도 옮기거나 보관함에 넣을 수 있음. 코인으로 소품 7개(벽: 포스터·시계·가랜드, 바닥: 방석·무드등·선인장·책 더미)를 사고, 소품은 다른 방으로 옮길 수 있음. 침실은 상자를 푼 뒤(2단계)부터 꾸밀 수 있음. 앞뒤 가림은 바닥 칸 위치로 앱이 계산
- 밤 분위기: 저녁 7시~아침 6시에는 방이 밤 그림으로 바뀌고 스탠드·모니터·꼬마전구·무드등에 불이 켜짐. 캐릭터 혼잣말도 밤 버전
- 돌아오면 반겨 주기: 이틀 이상 쉬다 오면 홈에 "다시 와줘서 반가워요". 기록 탭의 '연속 실천'은 '이번 달 해낸 날'로 바꿈
- 방 그림은 `tools/space_art/export.py`(Python, Pillow)로 다시 뽑을 수 있음. `assets/space/`의 PNG와 `lib/models/space_art.dart`(가구 칸 위치·그림 위치)를 함께 만든다
- 서버: 새 미션 id를 저장하려면 `supabase/migrations/20261105000011_more_solo_missions.sql`을 적용해야 함

## Windows에서 시작
Flutter를 PATH에 등록한 뒤 `시작하기.bat`을 더블클릭합니다.
처음에는 Android/web 기본 폴더와 패키지를 준비하며 시간이 걸릴 수 있습니다.
Chrome 창이 열리면 터미널 창은 켜 둡니다. 종료할 때 터미널에서 Ctrl+C를 누릅니다.

직접 실행할 경우:
1. `scripts\setup.bat` — 최초 환경 준비
2. `scripts\run_web.bat` — Chrome 시연 (고정 포트 7357)
3. `scripts\run_android.bat` — Android 기기 선택 실행
4. `scripts\test.bat` — 코드 분석·자동 테스트
5. `scripts\build_apk.bat` — Android 릴리스 APK 빌드

Android 실행에는 Android SDK와 연결된 기기 또는 에뮬레이터가 필요합니다.
웹 실행만으로 Android 동작까지 확인된 것은 아닙니다.

## 시연 순서 (약 1분)
홈의 어두운 침실 확인 → 오늘의 미션 하나 → 했어요 → 방에 햇빛이 들고 캐릭터가 한마디 → 오늘의 발견에서 사진 남기기 → 벽 액자 확인 → 벌집 보기 아이콘 → 내 기록.
타이머가 있는 미션은 타이머를 켜서 보여 줄 수 있습니다. 끝까지 기다릴 필요는 없습니다.

## 데이터
기록은 현재 기기/브라우저에만 저장됩니다. 다른 컴퓨터와 동기화되지 않습니다.
웹 주소나 포트가 달라지면 별도 저장 공간으로 처리됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.
타이머는 실행 중 화면에서 사용하는 보조 기능이며, 앱 종료 후 복원이나 백그라운드 알림은 지원하지 않습니다.

## Supabase 설정
로그인 없이 참여하려면 Authentication → Sign In / Providers에서 **Allow anonymous sign-ins**를 켜야 합니다.
발표장처럼 같은 와이파이에서 여러 명이 한꺼번에 들어오면 Authentication → Rate Limits의 익명 로그인 한도(기본 시간당 30회, IP 기준)를 늘려 둡니다.
`supabase/migrations/`의 SQL을 번호 순서대로 Supabase SQL Editor에서 실행합니다.
앱에는 publishable 키만 들어갑니다(`lib/config.dart`). service_role 키와 DB 비밀번호는 저장소에 넣지 않습니다.
