# 저두잇 — 1주차 주간보고

## 이번 주 목표
일상에서 쉽게 할 수 있는 작은 미션을 고르고, 완료한 내용을 기록하는 앱의 기본 흐름을 만든다.

## 이번 주 만든 내용
- 정리, 물 마시기, 독서, 걷기 중 미션을 고르는 홈 화면을 구성했다.
- 정리 미션에는 5분 타이머를 넣었다. 5분은 권장 시간이며, 먼저 마치면 완료 체크 후 저장할 수 있다.
- 완료 여부를 체크하고 짧은 메모를 남기면 기기에 기록되도록 구현했다.
- 기록을 최신순으로 보고, 확인창을 거쳐 삭제할 수 있게 했다.
- 홈에 오늘 완료한 횟수와 오늘 완료한 미션 표시를 추가했다.

## 사용 예시
물 한 잔 마시기 선택 → 시작하기 → 실제로 했어요 체크 → ‘아침에 물 한 잔 마심’ 입력 → 기록 저장 → 홈에서 오늘 완료 횟수 확인 → 내 기록에서 메모 확인.

## 수정하면서 보완한 점
처음 화면에서는 무엇을 했는지 바로 알기 어려워 오늘 완료 횟수를 넣었다. 기록이 없을 때는 미션을 고르도록 안내하고, 저장·불러오기·삭제에 실패하면 다시 시도할 수 있도록 메시지를 추가했다. 넓은 브라우저에서도 화면이 지나치게 늘어나지 않도록 본문 폭을 제한했다.

## 현재 상태와 남은 확인
Flutter 소스 수정과 자동 테스트 코드 보강까지 진행했다. 이번 작업 환경의 Flutter/Dart 실행 오류 때문에 분석, 자동 테스트, 웹 빌드, Android 설치 실행은 완료하지 못했다. 따라서 아직 ‘실기기 동작 확인 완료’나 ‘APK 완성’으로 제출하면 안 된다. 실행 후 확인한 항목만 아래에 체크한다.

- [ ] 홈에서 미션 4개가 보인다.
- [ ] 물 마시기 미션의 완료 체크 전에는 저장할 수 없다.
- [ ] 메모를 저장하면 오늘 완료 횟수가 증가한다.
- [ ] 앱을 다시 열어도 기록이 남는다.
- [ ] 기록 삭제를 취소하면 기록이 남는다.
- [ ] 정리 미션의 타이머가 시작된다.
- [ ] Android 기기에서 설치하고 같은 흐름을 확인한다.

## 다음 주 계획
1. Flutter 실행 환경을 정리하고 Android 기기에서 실행한다.
2. 친구 2~3명에게 미션을 고르고 기록하는 과정을 사용해 보게 한다.
3. 사용 중 헷갈린 점을 정리하고 화면을 수정한다.

## 아직 구현하지 않은 기능
로그인, 서버 저장, 친구 초대, 함께하는 챌린지, 사진 인증. ‘시안 비교’ 화면은 앞으로의 디자인을 비교하기 위한 고정 예시이며 실제 공동 미션 기능은 아니다.
