S/W 프로젝트 · WEEK 01

저두잇, 작은 실천부터

미션을 고르고, 실천하고, 기록하는 앱의 기본 흐름 만들기

소스 수정본 · 실제 실행 확인 필요

이번 주 목표

부담 없이 할 수 있는 일상 미션을 고르고, 완료한 내용을 다시 볼 수 있도록 개인 미션 기능을 구현한다.

01 · 미션 선택

오늘 하나만 골라보기

  • 정리 · 물 마시기 · 독서 · 걷기 4개 미션
  • 오늘 완료한 횟수와 미션 표시
  • 전체 기록으로 이동하는 버튼
02 · 실천과 기록

완료 체크 후 메모 남기기

  • 정리 미션의 5분 타이머와 진행 막대
  • 완료 체크 · 선택 메모 · 기기 저장
  • 기록 목록과 삭제 확인창

이렇게 사용해요

물 마시기 선택 → 시작 → 완료 체크·메모
→ 기록 저장 → 오늘 횟수와 내 기록 확인
메모 예시: “아침에 물 한 잔 마심” · 5분 타이머는 권장 시간이며 먼저 마쳐도 기록 가능

이번에 보완한 점

홈에서 오늘 한 일을 바로 알 수 있도록 완료 횟수를 추가했다. 빈 기록 화면에는 첫 미션 안내를 넣고, 저장이나 불러오기에 실패했을 때 메시지와 재시도 경로를 보완했다.

다음 주 할 일

  1. Android 기기에서 실행 확인
  2. 친구 2~3명에게 사용해 보게 하기
  3. 헷갈린 부분을 정리하고 수정하기

현재 확인된 범위

소스 수정과 자동 테스트 코드 보강까지 진행했다. 작업 환경의 Flutter/Dart 실행 오류로 분석·테스트·빌드 및 실기기 동작은 아직 확인하지 못했다. APK 완성본은 포함하지 않는다.

기록은 현재 기기·브라우저에만 저장됩니다. 로그인·서버·친구 초대·사진 인증은 이후 계획입니다. 시안 비교는 고정 예시입니다.
